4. The agent

seed list → search (Composio TAVILY_SEARCH) → fetch docs/pricing/MCP pages
  → [JS page? Composio TAVILY_EXTRACT → Playwright] → LLM extracts to fixed schema
  → CODE checks each quote is verbatim in the page → verifier LLM re-reads cited page
  → needs 2 independent pages for auth + self-serve → rule checks (dead links, contradictions)
  → low confidence / conflict ⇒ needs_human
  • Composio used: CLI-executed TAVILY_SEARCH and TAVILY_EXTRACT tools (logged-in CLI, no key in repo).
  • LLM: local Ollama (llama3.2 for pass 1, qwen2.5-coder:7b for pass 2): small models on purpose-constrained by code checks.
  • Where a human was needed: see HUMAN_INTERVENTIONS.md; count: flagged records.
