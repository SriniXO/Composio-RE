4. The agent

PASS 1 (baseline): search snippets -> small LLM -> record
PASS 2 (verified): search (Composio TAVILY_SEARCH) -> fetch docs/pricing/MCP pages
  -> [unreadable page? Composio TAVILY_EXTRACT -> Playwright] -> LLM extracts to fixed schema
  -> CODE checks each quote is verbatim in the page -> verifier LLM -> two-source rule -> rule checks
  -> low confidence / conflict => needs_human (flags only; does not fix)
PASS 3 (correcting, no LLM): re-read fetched text and CORRECT the record:
  auth keyword must appear on a page | API type from page text | "official MCP" only on the vendor's own domain
  | self-serve from pricing/access language | verdict re-derived from corrected fields
  • Composio used: CLI-executed TAVILY_SEARCH and TAVILY_EXTRACT tools (logged-in CLI, no key in repo).
  • LLM: local Ollama (llama3.2 for pass 1, qwen2.5-coder:7b for pass 2); pass 3 uses no LLM. Small models, bounded by code checks.
  • Where a human was needed: see HUMAN_INTERVENTIONS.md; count: flagged records.
